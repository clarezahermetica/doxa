## Purpose

Adaptive Reflection prevents DOXA from assuming that more reflection is always better. It makes intervention a policy decision that can itself be compared experimentally.

## Action set

<b>Continue</b> — proceed without additional intervention.

<b>Verify</b> — invoke a task-specific check.

<b>Retrieve</b> — obtain additional evidence or observations.

<b>Critique</b> — request independent review.

<b>Reflect</b> — generate a proposed lesson or diagnosis.

<b>Roll back</b> — restore a prior supported state and branch.

<b>Escalate</b> — request human review or mark the decision unresolved when automated evidence is insufficient.

<b>Stop</b> — terminate because the goal is met, the task is irrecoverable, or resource limits are exhausted.

## Initial controller

The first release should use explicit, inspectable rules. Examples: failing hidden or public tests may trigger critique; contradictory evidence may trigger verification; a verified regression may trigger rollback; repeated identical failures may escalate; an unsupported claim may trigger retrieval.

## Budgets

The controller should respect maximum model calls, token limits where available, wall-clock limits, critic-call limits, rollback depth, and environment-specific operation limits.

## Policy comparison

At minimum, DOXA should be able to represent:

- No extra review.
- Always review at defined milestones.
- Event-triggered adaptive review.
- Rollback-enabled recovery after specified verifier failures.

## Acceptance tests

1. Feed an event that maps to Continue.
2. Feed a verifier failure that maps to Critique or Verify.
3. Trigger rollback only after the configured recovery condition.
4. Enforce a resource budget and stop or escalate when exceeded.
5. Log the policy rule responsible for each intervention.
6. Compare two runs using different controller policies.

## Future direction

Learned or optimized controllers can eventually be trained from experiment history, but the initial policy should remain legible enough to debug and scientifically inspect.
